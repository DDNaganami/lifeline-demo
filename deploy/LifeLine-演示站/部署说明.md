# LifeLine 演示站 · 部署说明

这个文件夹是**可直接运行**的演示站，不需要安装任何依赖、不需要数据库。

```
LifeLine-演示站/
├── start-demo.bat     ← 双击这个启动
├── server.js          ← 极简静态服务器（零依赖，只用 Node 自带能力）
├── out/               ← 网页文件（约 0.9 MB）
└── 部署说明.md         ← 本文件
```

---

## 一、三步搞定

### 第 1 步：把整个文件夹复制到服务器

用远程桌面连上服务器，把 `LifeLine-演示站` 整个文件夹复制到任意位置，例如 `D:\LifeLine-演示站`。

### 第 2 步：装 Node.js（只需一次，约 3 分钟）

**先检查装没装**：在服务器上按 `Win + R`，输入 `cmd` 回车，然后输入：

```
node -v
```

- 显示版本号（如 `v20.11.0`）→ **已装好，跳到第 3 步**
- 提示"不是内部或外部命令" → **需要安装**

**安装方法（服务器能上网时）**：

1. 打开 https://nodejs.org/zh-cn/download
2. 下载 **Windows 安装包（.msi）**，选 **LTS** 版本
3. 双击安装，一路点"下一步"即可（不用改任何选项）
4. 装完后**关掉旧的 cmd 窗口，重新开一个**，再执行 `node -v` 确认

**服务器不能上网时**：下载 **Portable 的 .zip** 版本，在别的电脑上解压，
把其中的 `node.exe` 复制到 `LifeLine-演示站` 文件夹里即可。

### 第 3 步：双击 `start-demo.bat`

会弹出一个黑色窗口，显示：

```
  [1/3] Node.js ready: v20.11.0
  [2/3] Web files ready
  [3/3] Starting on port 8080 ...

  本机访问：   http://localhost:8080/
  局域网访问： http://192.168.x.x:8080/
```

**这个窗口不要关**，关掉就等于停止服务。要停止服务按 `Ctrl + C`。

想换端口：在 cmd 里执行 `start-demo.bat 9000`。

## 二、⚠️ 两个必须做的设置（否则外网访问不了）

很多人卡在这一步：**服务启动了，自己电脑能打开，别人打不开。**
99% 是下面两个原因之一。

### 设置 1：Windows 防火墙要放行这个端口

Windows Server 默认会拦住外部访问新端口。**在服务器上**用管理员身份打开 PowerShell
（开始菜单搜索 PowerShell → 右键 → 以管理员身份运行），执行：

```powershell
New-NetFirewallRule -DisplayName "LifeLine Demo 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
```

（如果换了端口，把两处 `8080` 都改成你的端口。）

想撤销这条规则：

```powershell
Remove-NetFirewallRule -DisplayName "LifeLine Demo 8080"
```

### 设置 2：路由器上再开一个端口转发

现在路由器**只转发了 5000**（你远程桌面用的那个），所以外网只能访问 5000。

需要在路由器上**再加一条转发规则**：

| 项目 | 填什么 |
|---|---|
| 外部端口 | 例如 `8080`（建议选一个好记的，或参照下表） |
| 内部 IP | 服务器的内网 IP（就是 `start-demo.bat` 显示的"局域网访问"里的那个 IP） |
| 内部端口 | `8080`（要和 start-demo.bat 的端口一致） |
| 协议 | TCP |

加完之后，同事就可以用 **`http://112.111.47.239:8080/`** 访问了。

> **注意**：路由器的设置只有你能改，我进不去。这是唯一需要你动手的一步。

## 三、关于端口的选择（这台服务器是和朋友共用的）

服务器上还有网页服务、Discord、Minecraft、求生之路，所以选端口要避开它们。
下面是我建议的候选，**都避开了常见默认端口**：

| 端口 | 说明 |
|---|---|
| **8080** | 默认选项，最直观 |
| **8520** | 更不容易和别人撞 |
| **9123** | 再稳一点 |

**怎么确认端口没被占用**（在服务器上执行）：

```powershell
netstat -ano | findstr :8080
```

- **没有任何输出** → 这个端口空闲，可以用 ✅
- 有输出（比如 `LISTENING`）→ 已被占用，换一个

**如果 `start-demo.bat` 报错说端口被占用**，它自己也会提示换端口，
直接执行 `start-demo.bat 8520` 即可。

## 六、常见问题

**Q：同事打不开，但我在服务器上能打开？**
A：两个原因，按顺序查：① Windows 防火墙没放行（见设置 1）② 路由器没加转发（见设置 2）。

**Q：网页打开是空白的？**
A：看浏览器控制台有没有报错；大概率是 `out` 文件夹没有被完整复制。
确认 `LifeLine-演示站\out\index.html` 存在。

**Q：黑窗口关掉了，网页就打不开了？**
A：是的，这个窗口就是服务本身。需要长期运行请看下面。

**Q：怎么让它开机自动启动、不用每次手动开？**
A：三种做法，从简单到规范：
1. 把 `start-demo.bat` 的快捷方式放进「启动」文件夹
   （`Win + R` → 输入 `shell:startup` → 把快捷方式拖进去）
2. 用任务计划程序，设置"计算机启动时"运行
3. 用 [NSSM](https://nssm.cc/) 注册成 Windows 服务（最规范，崩溃会自动重启）

**Q：会占用多少资源？**
A：几乎不占。这个服务只是把静态文件发出去，内存几十 MB，
不访问的时候 CPU 基本为 0。不会影响同一台机器上的 MC 服务器。

**Q：这段内容会不会被别人看到我填的信息？**
A：不会。所有反馈都存在**访问者自己的浏览器**里（localStorage），
服务器只是发网页文件，不接收也不保存任何数据。

**Q：怎么更新网页内容？**
A：把新的 `out` 文件夹整个替换掉，然后重启服务即可。

## 七、安全提醒（请务必看）

1. **远程桌面用的 administrator 密码已经出现在对话记录里**，建议部署完成后改一次密码。
2. 更稳妥的做法是给服务器开 SSH 并配置密钥登录，以后不用传密码；
   目前外网只开了 5000 端口，SSH（22）不通，所以暂时走远程桌面。
3. **不要把 server.js 改造成可以接收上传或写入文件的服务**——
   它现在的设计是**只读**的（只发文件、不写任何东西），这是刻意保持的最小攻击面。
4. 演示站不含任何账号、密码、数据库，所以即便被访问到也没有敏感数据可拿。
