## ⏳ 还差一步：路由器上加转发（只有你能做）

### 需要你做的事

在路由器「虚拟服务器」页面，**二选一**：

**方案 A（推荐，复用一条已经失效的转发）**

把它**改一条**：

| 外部端口 | 内部端口 | IP 地址 | 协议类型 |
|---|---|---|---|
| **25572** | **18080** | 192.168.1.75 | **TCP** |

**方案 B（新增一条）**

点「添加」，外部端口填一个新的（比如 `25576`，要避开已用的 25565–25575、5000、9987），
内部端口填 **18080**，IP `192.168.1.75`，协议 **TCP**。

### 改完之后

同事（以及你自己）就能打开：

- 方案 A → **http://112.111.47.239:25572/**
- 方案 B → **http://112.111.47.239:25576/**

## 常用运维命令（你可以直接粘到服务器上执行）

### 查看服务是否在跑

```powershell
Get-NetTCPConnection -LocalPort 18080 -State Listen
```

### 看访问日志

```powershell
Get-Content C:\LifeLine\logs\demo.log -Tail 30
```

### 重启服务

```powershell
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
Start-ScheduledTask -TaskName LifeLineDemo
```

### 停止服务（临时）

```powershell
Stop-ScheduledTask -TaskName LifeLineDemo
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
```

### 彻底卸载（如果不想留了）

```powershell
Stop-ScheduledTask -TaskName LifeLineDemo
Unregister-ScheduledTask -TaskName LifeLineDemo -Confirm:$false
Get-Process node -ErrorAction SilentlyContinue | Stop-Process -Force
Remove-NetFirewallRule -DisplayName "LifeLine Demo 18080"
Remove-Item C:\LifeLine -Recurse -Force
# 再让朋友把路由器上那条 25572 → 18080 的转发删掉
```

## 🔐 安全说明与建议

### 关于 Administrator 密码（重要：这是共享账号，**不要改**）

- **我没有改动过任何密码或账号设置**。服务器记录显示密码最后设置时间是
  `2025-04-04 19:24:48`，早于本次部署，可自行用下面命令核对：

  ```powershell
  Get-LocalUser -Name 'Administrator' | Select-Object Name, Enabled, PasswordLastSet, LastLogon
  ```

- ⚠️ **这个 Administrator 账号是多人共用的（不止你一人在用远程桌面）**，
  **改密码会直接影响其他人**。所以：
  - **不要为了安全去改这个密码**
  - 如果确实觉得密码出现在聊天记录里有风险，正确做法是**和朋友一起商量**，
    由账号所有人决定，并同步通知所有使用者
  - 更稳妥的长期方向是：**各自用独立账号 + 禁用 Administrator 远程登录**，
    但这是朋友那边的运维决定，不属于本项目范围

### 可以安全做的（不影响他人）

1. **关闭 SSH 密码登录**（我们用的是公钥，不需要密码登录）。
   这一步只影响 SSH，**不影响远程桌面**：
   ```powershell
   $f = "$env:ProgramData\ssh\sshd_config"
   (Get-Content $f) -replace '^#?PasswordAuthentication.*', 'PasswordAuthentication no' |
     Set-Content $f -Encoding ascii
   Restart-Service sshd
   ```
   > 执行前先确认公钥登录是通的（现在就是通的），否则会把自己关在门外。
2. **如果不再需要 SSH**：停掉 sshd 服务、删掉防火墙规则，
   或让朋友删掉路由器上 `25573 → 22` 那条转发。**这不会影响远程桌面**（它走的是 5000 → 3389）。
